Widget settings let you configure the appearance and behavior of the Kashfy website chat widget, and copy the installation snippet for your site.

Navigate to **Dashboard → Settings → Widget**.

<Info>
  The website widget is available on the **Team plan and above**. Solo plan accounts see an upgrade prompt on this page instead of the widget configuration.
</Info>

## What the widget does

The website widget embeds a chat interface directly on your clinic's website. Patients can start a conversation, ask questions, and book appointments without leaving your site. The same AI agent handles widget conversations as WhatsApp conversations.

## Configuration options

The Widget settings page reuses the same panel as **Dashboard → Widget**, which includes:

- **Widget color** — matches your clinic's primary brand color
- **Welcome message** — the first message patients see when they open the widget
- **Position** — bottom-left or bottom-right corner of the page
- **Language** — Arabic, English, or auto-detect based on the visitor's browser

## Installation snippet

At the bottom of the settings page, you'll find a JavaScript snippet to paste into your website's HTML, just before the closing `</body>` tag.

For a full step-by-step installation guide, see [Widget Installation](/widget/installation).

<Note>
  Each organization has a unique widget ID embedded in the snippet. Do not share the snippet from one clinic with another — each clinic needs its own.
</Note>

## Solo plan upgrade

If you're on the Solo plan, this page shows an upgrade prompt. The Solo plan is WhatsApp-only. To enable the website widget, upgrade to the Team plan or above from the upgrade page.
