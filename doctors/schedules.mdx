---
title: 'Doctor Schedules'
description: "Set each doctor's weekly hours per branch and choose time-slot or walk-in queue booking"
---

A doctor's schedule decides which times the AI, your widget, and your staff can book. Open the doctor from **Dashboard → Doctors** and go to **Availability**.

## Branches

Under **Doctor's branches**, tap each branch the doctor works at. Hours are set separately for each branch. If the doctor has several branches, pick one in the branch selector to edit its hours.

## Booking mode

Each branch has its own booking mode:

| Mode | How patients book |
|------|-------------------|
| **By time** | Patients pick a time slot. Slots are cut from the doctor's hours using the **session** length (10, 15, 20, 30, 45, or 60 minutes). |
| **Walk-in queue** | Patients get a queue number for the day instead of a time. Set **patients/day** to cap how many can book each day. |

## Weekly hours

Days run **Saturday to Friday**. For each day:

1. Tick the day to open it.
2. Set **from** and **to** times.
3. In **By time** mode set the session length; in **Walk-in queue** mode set patients per day.

Each day has one block of hours per branch. A doctor who works mornings at one branch and evenings at another sets each block on its branch.

**Example (By time):**

```
Saturday 09:00 to 13:00, 20-minute sessions
Slots: 09:00, 09:20, 09:40 ... 12:40
```

<Warning>
  A doctor can't be in two branches at once. If hours overlap with the doctor's hours at another branch, Kashfy shows the conflict and won't save until you fix it.
</Warning>

## Fully booked days

When every slot (or queue place) on a day is taken, the AI offers the next day with space. It never double-books a slot.

## Checking the day's bookings

Use **Dashboard → Appointments** with the date picker and search for the doctor's name. Doctors see their own day in the [Doctor Portal](/doctors/doctor-portal).
