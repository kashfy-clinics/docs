سجّل كل ما يُصرف: الإيجار، والرواتب، والمستلزمات، والمرافق، والمشتريات لمرة واحدة. تدخل المصروفات في حساب [الأرباح والخسائر](/finance/pnl). انتقل إلى **لوحة التحكم ← الحسابات ← المصروفات**.

يعرض التبويب **إجمالي المصروفات** للفترة المحددة أعلى القائمة.

## إضافة مصروف [#adding-an-expense]

اضغط على **مصروف جديد** واملأ الحقول التالية:

| الحقل | ملاحظات |
|-------|-------|
| **الفئة** | مطلوب. ابحث، أو اكتب فئة جديدة واضغط على **إضافة** |
| **النوع الفرعي** | اختياري |
| **وصف** | تفاصيل اختيارية، مثل اسم المورد أو رقم الفاتورة |
| **المبلغ (ج.م)** | مطلوب، ويجب أن يكون أكبر من 0 |
| **طريقة الدفع** | كاش، أو بطاقة، أو إنستاباي، أو تحويل، أو أخرى |
| **التاريخ** | مطلوب |
| **الفرع** | فرع محدد، أو كل الفروع (للعيادات متعددة الفروع) |
| **تكرار** | مرة واحدة، أو أسبوعي، أو شهري، أو ربع سنوي، أو سنوي |
| **ينتهي في** | اختياري، للمصروفات المتكررة |

## المصروفات المتكررة [#recurring-expenses]

عند اختيار تكرار غير **مرة واحدة**، يضيف كشفي نسخة جديدة من المصروف تلقائيًا في كل تاريخ استحقاق، حتى تاريخ الانتهاء إذا حددته.

اضغط على **المتكررة** لعرض جميع المصروفات المتكررة مع تاريخ الاستحقاق التالي وتاريخ الانتهاء لكل منها، ولتعديل أي منها.

<Tip>
  استخدم المصروفات المتكررة للمبالغ الثابتة مثل الإيجار أو الرواتب. أما الفواتير المتغيرة، مثل الكهرباء، فأضفها واحدة تلو الأخرى بالمبلغ الفعلي.
</Tip>

## التصفية [#filtering]

يمكنك تصفية القائمة حسب **الفئة** أو **الفرع**، إلى جانب الفترة الزمنية المحددة في الأعلى.

## التعديل والحذف [#editing-and-deleting]

اضغط على أيقونة القلم بجانب أي مصروف لتعديله، أو على أيقونة الحذف لإزالته. بالنسبة للمصروف المتكرر، اختر أحد الخيارات التالية:

- **هذا المصروف فقط**
- **أوقف التكرار (احتفظ بالسابق)**
- **احذف كل شيء**
