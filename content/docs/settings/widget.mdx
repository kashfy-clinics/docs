Go to **Settings → Widget**. This page appears for clinics.

## Website widget snippet

The code card shows your ready-to-paste snippet with a **Copy** button. Paste it just before the closing `</body>` tag on your website. Full steps for WordPress and Shopify are in [Widget Installation](/widget/installation).

<Info>
  The website widget is available on the **Team plan and above**. On Solo plans this part of the page shows an upgrade prompt with a **View plans** button instead of the snippet.
</Info>

The widget's look (button, colors, greeting) is fixed. The only option is the language, set by `data-lang` in the snippet.
