Every member of your organization has one role.

| Role | Who it's for |
|------|-------------|
| **Owner** | The account that created the organization |
| **Admin** | A manager with the same access as the owner |
| **Employee** | Reception and front desk |
| **Doctor** | A clinician who sees their own patients in the [Doctor Portal](/doctors/doctor-portal) |

## What each role can do

| | Owner | Admin | Employee | Doctor |
|---|:---:|:---:|:---:|:---:|
| See appointments | All | All | All (or their branches) | Own only |
| Create bookings | Yes | Yes | Yes | No |
| Move appointment stages | Yes | Yes | Yes | Own only |
| Record payments | Yes | Yes | Yes | No |
| Void payments | Yes | Yes | No | No |
| Write diagnosis, prescriptions, lab and scan orders, medical alerts | Yes | Yes | No (read only) | Yes |
| See patients | All | All | All (or their branches) | Only patients they've seen |
| Edit doctors, services, clinic settings | Yes | Yes | View only | No |
| AI Agent, Finance, WhatsApp Ads | Yes | Yes | No | No |
| Invite and remove employees | Yes | Yes | No | No |
| Add or remove admins | Yes | No | No | No |
| Enable lab or radiology modules | Yes | No | No | No |
| Request subscription cancellation | Yes | No | No | No |

<Info>
  Owners and admins share every management permission. The differences are only the owner-only actions at the bottom of the table.
</Info>

## Branch restrictions

When you invite an employee, or add a doctor, you can choose specific branches. They then only see appointments and patients for those branches. Owners and admins always see every branch.

## Solo-doctor organizations

If your plan allows one doctor, the doctor role isn't offered on the Team page. The owner can write chart notes directly.

## Changing a role

Roles are set when you invite someone. To change a role, remove the member in [Team Members](/team/members) and invite them again with the new role.
