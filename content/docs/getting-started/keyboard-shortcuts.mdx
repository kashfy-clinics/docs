---
title: 'Keyboard Shortcuts'
description: 'Move around Kashfy and work faster from the keyboard'
---

On a computer, Kashfy has keyboard shortcuts for the things you do most. Press **?** anywhere (outside a text box) to see them all, or open the account menu at the bottom of the sidebar and choose **Learn more**, then **Keyboard shortcuts**.

On a Mac, use **⌘ Command** wherever this page says **Ctrl**. The shortcuts also work with the Arabic keyboard layout switched on.

<Info>
  Shortcuts are for computers. On phones and tablets they don't appear in menus or tooltips.
</Info>

## General

| Shortcut | What it does |
|----------|--------------|
| **Ctrl+K** | Search this page, or jump to **Patients** and search there if the page has no search box |
| **Ctrl+B** | Show or hide the sidebar |
| **Ctrl+Shift+L** | Switch between dark and light mode |
| **Ctrl+Shift+,** | Open **Settings** |
| **?** | Show all keyboard shortcuts |

## Go to

Press **G**, then a letter (within a second):

| Shortcut | Goes to |
|----------|---------|
| **G then D** | Dashboard |
| **G then A** | Appointments |
| **G then P** | Patients |
| **G then C** | Conversations |
| **G then I** | Clinic Agent (clinic) or Assistant (doctor view) |
| **G then F** | Finance |
| **G then S** | Settings |

You only get the pages you can open. For example, **G then F** does nothing without access to Finance.

## Doctor Assistant

On the [Assistant](/doctors/assistant) page:

| Shortcut | What it does |
|----------|--------------|
| **Ctrl+K** | Search your conversations |
| **Ctrl+Shift+O** | Start a new chat |
| **Ctrl+B** | Show or hide the chat history |
| **Ctrl+U** | Attach files or photos |
| **Enter** | Send the message |
| **Shift+Enter** | New line in the message |
| **Esc** | Stop the reply |
| **↑** (in an empty message box) | Bring back your previous messages, one by one |

## In forms and dialogs

| Shortcut | What it does |
|----------|--------------|
| **Ctrl+Enter** | Save a private note, or write the medical report |
| **Esc** | Close a dialog |
