تابع سلامة الخدمات الأساسية في كشفي واطّلع على سجل الأعطال السابقة.

## الحالة الحالية [#current-status]

جميع الأنظمة **تعمل بشكل طبيعي** حاليًا.

| الخدمة | الحالة |
|---------|--------|
| المساعد الذكي (واتساب) | يعمل |
| المساعد الذكي (الويدجت) | يعمل |
| لوحة التحكم | تعمل |
| حجز المواعيد | يعمل |
| واتساب (رقم كشفي المشترك) | يعمل |
| الفواتير والمدفوعات | تعمل |

<Info>
  تُحدَّث هذه الصفحة يدويًا أثناء الأعطال. فعّل إشعارات المتصفح من **لوحة التحكم ← الإعدادات ← الإشعارات** حتى يرى فريقك الرسائل والحجوزات الجديدة فور وصولها.
</Info>

## الإبلاغ عن عطل [#reporting-an-outage]

إذا واجهت مشكلة تبدو عطلًا عامًا في النظام (وليست مرتبطة بإعدادات عيادتك تحديدًا):

1. أرسل بريدًا إلكترونيًا إلى [support@kashfy.site](mailto:support@kashfy.site) بعنوان **Possible Outage**
2. اذكر اسم عيادتك ووصفًا لما لا يعمل
3. سيحقق الفريق في المشكلة ويحدّث هذه الصفحة عند تأكيد وجود عطل

## سجل الأعطال [#incident-history]

لا توجد أعطال خلال آخر 90 يومًا.
