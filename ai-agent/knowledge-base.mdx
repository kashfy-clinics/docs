The Knowledge Base holds information the AI uses beyond your clinic profile, doctors and services: price lists, insurance details, preparation notes, FAQs, anything your receptionist answers every day.

Open **Knowledge** in the sidebar. Everyone on the team can read it; only owners and admins can add, edit or delete entries.

## Add a text note

The quickest way to add information.

<Steps>
  <Step title="Click Add text note">
    A small form opens.
  </Step>
  <Step title="Write the information">
    Add an optional title (for example "Insurance") and the text. Arabic or English both work.
  </Step>
  <Step title="Click Add">
    The note is saved and the AI can use it right away.
  </Step>
</Steps>

You can edit or delete any note later from the list.

## Upload a file

Click **Upload file** and pick a text file.

| | |
|---|---|
| **Supported** | `.txt`, `.md`, `.csv`, `.json` |
| **Not supported yet** | PDF, Word (`.doc`, `.docx`), images |
| **Max size** | 10 MB per file |

<Info>
  Have a PDF or Word price list? Copy the text and paste it into a text note, or save it as a `.txt` file first.
</Info>

## How the AI uses it

For each patient message, the AI looks up the entries most related to what the patient asked and uses them to write its reply in its own words. It doesn't read the whole knowledge base word for word every time, so clear, focused entries work best.

## Tips

<Tip>
  One topic per entry. "Insurance companies we accept" and "Lab test prices" as separate notes are easier for the AI to find than one long note covering everything.
</Tip>

<Tip>
  After adding or changing an entry, ask a related question in **AI Agent → Patient** to check the answer.
</Tip>

<Warning>
  Deleting an entry removes it from the AI immediately. If patients ask about that topic, the AI will no longer have the answer.
</Warning>

Doctor fees, working days and services come from their own pages, so you don't need to repeat them here. Keep those pages up to date instead.
